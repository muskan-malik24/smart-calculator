# 🧮 Smart Calculator

A simple and responsive Smart Calculator built using **HTML, CSS, and JavaScript**. It performs basic arithmetic operations with a clean and user-friendly interface.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal number support
- 🧹 Clear button to reset the display
- ⌫ Backspace button to remove the last character
- ✅ Error handling for invalid expressions
- 📱 Responsive design for smaller screens
- 🎨 Modern UI with hover and click effects

## 🛠️ Technologies Used

- **HTML5** — Structure of the calculator
- **CSS3** — Styling, layout, and responsive design
- **JavaScript** — Button interactions and calculation logic

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start calculating!

You can also use the **Live Server** extension in VS Code to run the project.

The calculator features a clean interface with a display screen, number buttons, arithmetic operators, a clear button, and an equals button.
